Microsoft Visual Studio

要求: Windows Server 2003 Service Pack 1

在安装 Visual Studio 之前，计算机上必须装有 Windows Server 2003 Service Pack 1。您可以从 http://v5.windowsupdate.microsoft.com/v5consumer/default.aspx?ln=zh-cn 下载并安装该 Service Pack。在安装该 Service Pack 之后，需要重新启动计算机。Visual Studio 安装程序 不会自动重新启动。要重新启动 Visual Studio 安装程序，请双击 安装源 CD、DVD 或网络共享上的 setup.exe，或单击 下载网站上的适当链接。

注意: 强烈建议您定期检查并 安装操作系统的更新。要搜索操作系统的 更新，请参见 http://v5.windowsupdate.microsoft.com/v5consumer/default.aspx?ln=zh-cn。

为什么要安装 Service Pack?

Service Pack 是产品更新发布的途径。Service Pack 所包含的更新可用于提高系统可靠性、程序兼容性、 安全性等等。有关 Microsoft Service Pack 的详细信息，请参见 http://support.microsoft.com/default.aspx?scid=fh;ZH-CN;sp。
