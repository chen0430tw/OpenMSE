介绍

此 Visual C# 初学者工具包是一个可以直接运行的 Windows 屏幕保护应用程序。此屏幕保护程序显示一系列图像（这些图像可以是默认图像，也可以是来自您指定目录的图像），这些图像上重叠了来自活动 Internet RSS（Really Simple Syndication，真正简单的聚合）源的文本。该项目可以直接编译并运行，但您也可以通过少量的额外 C# 编程对它进行自定义。在扩展屏幕保护程序一节中，我们提供了一组建议。您还可以免费使用此源代码作为自己项目的基础，并可与其他人共享您的工作或将该工作上载到 Internet。


注意：此文档假定您对编程概念和 Visual C# 环境有基本了解。可以通过单击主菜单上的“帮助”，然后选择“目录”、“索引”或“搜索”来了解有关产品文档中这些主题的更多信息。也可以通过如下方法访问帮助：将鼠标光标定位在语言关键字或用户界面元素（例如窗口或对话框）上，然后按 F1。

目标

通读此初学者工具包文档后，您将了解如何安装和配置屏幕保护应用程序，源代码是如何组织的，应用程序是如何工作的，以及如何使用 Visual C# 对应用程序进行自定义。此初学者工具包演示了下面一些技术：

  • GDI+ — 设置图形和文本的格式并进行显示
  • System.XML — 使用 XmlTextReader 和 XmlNode 读取包含 RSS 源信息的 XML 文件
  • WebClient 类 — 从网页下载数据
  • RSS — 包含 RSS 源、频道和项
  • C# 2.0 语言 — 包括泛型

入门

生成并运行屏幕保护程序

将项目加载到 Visual C# 环境后，只需一个步骤即可编译和运行程序。

生成并运行屏幕保护应用程序

  • 按 F5 以在“调试器”下生成并启动屏幕保护程序。

屏幕保护程序启动并开始显示来自 RSS 源的最新文章。按任意键或移动鼠标都将导致退出屏幕保护程序。

快速更改源代码

通过编辑源代码来更改该程序的工作方式非常简单。下面是一个示例，该示例将您自己的文本字符串添加到屏幕保护程序的显示内容中。

显示额外的文本行：

  1. 找到“解决方案资源管理器”窗口；其默认位置位于 Visual C# 环境的右上角。在“解决方案资源管理器”窗口中右击“ScreenSaverForm.cs”，然后选择“查看代码”，在代码视图中打开“ScreenSaverForm.cs”。
  2. 滚动源代码直到看见 OnPaint 方法，或从代码视图右上方的下拉列表中选择此方法。

  3. 在此方法的结尾处键入以下代码：

    e.Graphics.DrawString("<您的姓名>C# Screen Saver", rssView.TitleFont, Brushes.Orange, new PointF(0, 0));

  4. 按 F5 再次运行该应用程序。

现在该屏幕保护程序上显示了标题。

访问“选项”对话框

屏幕保护程序初学者工具包也包含一个“选项”对话框，用户可以在此对话框中更改屏幕保护程序的设置。若要在 Visual Studio 中运行“选项”对话框，当打开可执行文件时，您将需要直接将命令行参数发送给该文件。如果使用的是 Windows 98，请注意该计算机的其他用户也可看见在“选项”对话框中输入的数据。

强制显示“选项”对话框：

  1. 打开“解决方案资源管理器”，双击“屏幕保护程序”项目下的“属性”节点。
    这将会显示用于配置项目的选项。
  2. 单击“调试”选项卡，然后找到“命令行参数”文本框。
  3. 在文本框中键入 /c。
    这样便可通知 Visual C# 使用 /c 命令行参数运行屏幕保护程序。
  4. 按 F5 启动该应用程序。
    出现“选项”对话框。
  5. 通过选择其他背景图像目录或输入新的 RSS 源来测试这些选项。
  6. 单击“确定”关闭对话框。

在选项模式中更改设置后，可通过输入 /s（而不是 /c）作为命令行参数来再次运行该屏幕保护程序。

在计算机上安装屏幕保护程序

下面的步骤描述了如何在计算机上安装屏幕保护程序。

安装屏幕保护程序：

  1. 如果还未安装初学者工具包，请将它加载到 Visual C# 中。

  2. 在“文件”菜单中，单击“全部保存”。

  3. 如果提示您输入此项目的保存位置，请选择一个目录，或接受默认位置。请记住保存项目的位置，默认情况下它位于 \My Documents\Visual Studio 2005\Projects 下的目录中。

  4. 在“生成”菜单上，单击“生成解决方案”。
    这可生成屏幕保护程序的可执行文件。

  5. 打开在步骤 3 中指定的包含已保存项目的目录。

  6. 打开 bin\Debug 子目录。可执行文件的调试版本就放置在这里。它的默认名为 ScreenSaver1.exe，但是您也许在第一次创建该项目时已经为它指定了其他名称。将此文件的扩展名“.exe”更改为“.scr”。

    注意：如果您在 Windows 资源管理器中看不到文件扩展名，请在“工具”菜单下单击“文件夹选项”，然后单击“查看”选项卡，取消选中标记为“隐藏已知文件类型的扩展名”的复选框。

  7. 右击 .scr 文件并选择“安装”。
    这将打开“Windows 屏幕保护程序”对话框。

  8. 在“Windows 屏幕保护程序”对话框中单击“预览”按钮。
    屏幕保护程序启动。按任意键可停止它。

  9. 在“Windows 屏幕保护程序”对话框中单击“设置”按钮以查看屏幕保护程序选项。尝试更改背景图像或 RSS 源。

  10. 单击“确定”。
     

您现在已安装了自己的 Windows 屏幕保护程序。

与朋友共享您自己的屏幕保护程序

现在您拥有了自定义版本的屏幕保护程序，便可与朋友和家人共享此程序。请注意，该屏幕保护应用程序使用 2.0 版的 .NET Framework，因此运行该程序的任何计算机都需要安装此版本的 Framework。.NET Framework 作为 Visual Studio 的一部分进行安装，但它也可以从 Microsoft .NET Framework Developer Center 直接安装。如果您计划与朋友共享屏幕保护程序，您还应告诉他们需要安装新版的 .NET Framework。

屏幕保护程序的工作方式

当 Windows 由于不活动状态持续了一段时间而激活屏幕保护程序时，它将启动一个名为“ScreenSaver1.scr”的可执行文件，除非您已为该文件指定了其他名称。

如果没有请求屏幕保护程序打开“选项”对话框，则该程序会创建全屏的 Windows 窗体，插入默认背景图像，并访问 Internet 以下载和显示来自 RSS 源的数据。两个计时器会更新当前所选主题并更改背景图像。

如果移动鼠标或单击任意一点，或者按任何键，该程序都会立即退出。

屏幕保护程序项目文件

此项目包含八个不同的 C# 源代码文件。

Program.cs 包含 Main() 方法（程序开始执行的位置）和用于处理命令行开关的代码
OptionsForm.cs 包含显示设置选项的 Windows 窗体。通过此对话框，可选择屏幕保护程序运行时要使用的背景图像和 RSS 源。
ScreenSaverForm.cs 包含主屏幕保护程序 Windows 窗体。在此全屏窗体上读取并显示用户选择的背景图像和 RSS 源。
RSSFeed.cs 包含表示 RSS 2.0 源的类。
RssChannel.cs 包含表示 RSS 频道的类。所有 RSS 源中都有一个频道。它表示文章的集合。
RSSItem.cs 包含表示 RSS 项的类。RSS 频道可拥有任意数量的 RSS 项。一个 RSS 项表示一篇文章、一个博客贴子或一段新闻报道。
Item.cs 包含表示项的类，即具有标题和说明的对象。
ItemDescriptionView.cs 包含用来显示 RSS 源项的说明的代码。它以慢慢淡入淡出的效果显示项的文本。
ItemListView.cs 包含用来显示 RSS 源项的标题的代码。它跟踪当前所选文章，并可向前或向后滚动该文章。

概念

Windows 与屏幕保护程序的交互方式

Windows 屏幕保护程序是一个可执行文件，用于打开显示不断变化的图形显示（例如“飞越星空”或选定的一组照片）的全屏窗口。任何可执行文件都可用作 Windows 屏幕保护程序。要使可执行文件出现在屏幕保护程序选择对话框中，只需将该文件放在 Windows 目录中（如果使用的是 Windows 98 或 Windows XP，则该目录为系统驱动器中的 \Windows\System32；如果使用的是 Windows NT 或 Windows 2000，则该目录为 \WinNT\System32）。

当 Windows 运行屏幕保护程序时，它使用以下三个命令行选项之一启动该程序：

  • /s – 通知屏幕保护程序开始显示。
  • /c – 通知屏幕保护程序打开其“设置”对话框。
  • /p – 通知屏幕保护程序显示较小的预览。

此初学者工具包在 Program.cs 源文件中处理这些参数。当您查看该文件中的代码时，将发现此初学者工具包没有实现 /p 参数。

使用设置和资源设计器存储选项

初学者工具包可在两种不同模式中运行，因此它需要用一种方法来在这两种会话之间存储它的设置，这就需要使用设置设计器。通过在“解决方案资源管理器”中右击 ScreenSaver 项目节点，选择“属性”，然后单击“设置”选项卡，便可看到此设计器。使用此设计器，您可以列出程序希望设置并能够以下面的格式从代码访问的所有设置：

Properties.Settings.Default.<SettingName>


类似地，资源设计器用于存储默认的背景图像和 RSS 源。通过在“解决方案资源管理器”中右击 ScreenSaver 项目节点，选择“属性”，然后单击“资源”选项卡，便可看到此设计器。

XML 和 RSS

RSS 源的格式为 XML，用于汇总 Web 上内容。站点经常使用它们来发布自己的当前新闻文章或博客贴子的列表。RSS 源具有包含一个 <channel> 节点的 <rss> 节点。<channel> 节点有一个或多个 <item> 节点，每个 item 节点表示源中的一篇文章或一个博客贴子。它还包含一个 <title> 元素，该元素含有频道的标题。每个 <item> 都可包含标题、链接和说明。下面是一个非常简单的示例。

 

<rss version="2.0">

  <channel>

    <title>我的 RSS 源</title>

    <description>一些文章。</description>

    <link>http://msdn.microsoft.com/</link>     

    <item>

      <title>文章 1</title>

      <description>文章摘要。</description>

      <link>http://msdn.microsoft.com/netframework</link>

    </item>

    <item>

      <title>文章 2</title>

      <description>一些其他文章摘要。</description>

      <link>http://msdn.microsoft.com/vcsharp/</link>

    </item>

  </channel>

</rss>

扩展屏幕保护程序

添加键盘支持

增强屏幕保护程序的一种简单方法是添加键盘支持。例如，可允许用户使用光标键来选择当前的 RSS 项。以下步骤说明如何进行操作。

添加键盘支持：

  1. 在“解决方案资源管理器”中，右击“ScreenSaverForm.cs”，然后选择“查看设计器”。
  2. 如果未显示“属性”窗口，则通过单击“视图”菜单然后选择“属性窗口”来打开它。
  3. 在“属性”窗口顶部的下拉列表中选择“ScreenSaverForm”。
  4. 单击“事件”按钮（闪电形按钮）来查看窗体可引发的事件。
  5. 找到 KeyDown 事件。它列出一个方法 ScreenSaverForm_KeyDown 作为该事件的处理程序。
  6. 双击 KeyDown 事件。
    这可打开代码视图，并显示 ScreenSaverForm_KeyDown 方法。

  7. 使用以下内容替换行 Close();：

    switch (e.KeyCode)

                {

                    case Keys.Down:

                         // 向下滚动文章。

                         rssView.NextArticle();

                         break;

                     case Keys.Up:

                         // 向上滚动文章。

                         rssView.PreviousArticle();

                         break;

                     default:

                         Close();

                         break;

                 } 
  8. 保存文件，然后按 F5 运行此项目。
  9. 此屏幕保护程序运行时，您可以按“向上键”和“向下键”来更改当前所选文章。

更多建议

该屏幕保护应用程序设计为易于扩展和自定义。下面是如何扩展它的一些建议：

  • 选择自己的内置默认图像：
    将默认的屏幕保护程序图像更改为您所选择的图片。
  • 在右上角显示气象信息：
    使用 Web 服务（如此服务）来检索气象信息，然后在屏幕的右上角显示一些当前的气象详细信息。
  • 生成自己的屏幕保护程序：
    使用另一个显示完全不同的屏幕保护程序的 Windows 窗体替换 ScreenSaverForm。看看能否从现有的 Windows 屏幕保护程序中得到些启发，想出一些新的创意吗？（“飞越星空”和“三维管道”就是这样完成的。）Program.cs 文件处理所有支持屏幕保护程序的命令行选项。
  • 多个 RSS 源：
    扩展“选项”对话框以使用户能够选择一组用来从中收集新闻文章的 RSS 源。这可通过几种方法来实现：
    1.“选项”对话框使用户能够选择包含 RSS 源列表的 OPML 文件，
    - 或 -
    2.“选项”对话框使用户能够填写 RSS 源列表。
    加载屏幕保护程序时可选择随机的新闻源，之后，当屏幕保护程序每次显示完一个新闻源的内容时，都可选择一个新的源。
  • 完成 RSS 类的实现：
    随此初学者工具包提供的 RSS 类不支持整个 RSS 2.0 规范。可将规范的其余部分添加到这些类中。然后可将这些类打包为 dll，并在其他应用程序中重新使用。
  • 重用 RSS 类：
    RSS 类可以在另一个应用程序中重用。一些可能的用途包括: 编写自己的 RSS 聚合程序，或创建每小时弹出新文章的系统栏应用程序。
