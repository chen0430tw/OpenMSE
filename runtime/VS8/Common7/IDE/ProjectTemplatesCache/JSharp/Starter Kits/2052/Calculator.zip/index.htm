运行应用程序

“计算器”初学者工具包是一个示例应用程序，它演示了使用 Visual J# 可以进行的操作。该应用程序可以自由配置，允许您对它进行个性化设置，它还包含全部代码，因此您可以查看它是如何工作的。

 

加载和运行应用程序

1.     在“新建项目”对话框中，从已安装的模板中选择“初学者工具包 - 计算器”，然后单击“确认”。

将打开一个基于“计算器”初学者工具包模板的新项目。

2.      按 F5 以按原样运行应用程序。

 

浏览代码

1.       从“视图”菜单中选择“解决方案资源管理器”（如果它没有打开的话）。

2.       您可以在“解决方案资源管理器”中单击 Calculator.jsl 启动它。或者，您也可以在用户界面包中浏览，通过单击 CalculatorForm.jsl 在设计器中打开主窗体。

 

扩展代码

1.       修改所需的文件，然后按 F5 以生成并运行扩展的应用程序。

应用程序结构

此应用程序是围绕“模型-视图-控制器”(MVC) 结构建模的。

MVC 模式将应用程序的建模、表示和基于用户输入的操作分成以下三个独立的单元：

 

视图

视图管理信息的显示。

CalculatorForm.jsl 包含使用 Windows 窗体设计器开发的基于 Windows 窗体的用户界面。

 

 

模型

模型管理应用程序的行为和数据，响应对状态信息的请求（通常来自视图），响应更改状态的指令（通常来自控制器）。

Engine.jsl 管理计算器的行为和状态。引擎实例化下列类：

          Display.jsl 继承 java.util.Observable，并管理要在计算器上显示的数据。实现 java.util.Observer 可使 CalculatorForm 注册为显示屏 Observable 的有效观察者。这种 Observer-Observable 组合（或模式）使得只要显示屏更改了状态，CalculatorForm 就可以自己自动更新。

          OperandStack.jsl 包含一个操作数栈，这些操作数根据运算符的优先级被送入堆栈，或从堆栈中弹出。

          OperationStack.jsl 包含一个操作栈。

          Mode.jsl 包含有关基础模式的信息，例如，“Inv”或“Hyp”模式是打开的还是关闭的。它还包含“enum”数据类型，如 AngleMode（度、弧度等）和 Base （二进制、十进制等）

 

控制器

控制器解释来自用户的鼠标和键盘输入，通知模型和/或视图进行适当更改。

Calculator.jsl 是此应用程序的入口点。它实例化 CalculatorForm 和引擎，充当视图和模型之间的桥梁。

 

实现的操作

这里实现的所有操作都利用了运行库多态性的强大技术。每个属于 Operation 类型的类都实现在 Operation 接口中声明的 operate() 方法。于是，引擎可以对对象的实际类型（例如正弦值、Pi 或加法等）动态调用 operate() 方法，而无需在编译时显式指定。

 

Operation.jsl 接口通过抽象类来实现，例如 ZeroaryOperation.jsl、UnaryOperation.jsl、BinaryOperation.jsl 和 MemoryOperation.jsl。

 

 

抽象类 UnaryOperation 通过“一元”函数实现，这些函数的示例有：

          Sine.jsl 实现用于计算角的正弦值的应用程序逻辑。

          NaturalLog.jsl 实现用于查找显示数的自然对数的逻辑。

          Exponential.jsl 包含用于获取一个数的指数的逻辑。

          Square.jsl 实现计算平方的功能。

          FEMode.jsl 实现用于打开和关闭科学计数法的逻辑。

          Equals.jsl 提交运算。

扩展应用程序

应用程序中已内置了一定程度的冗余，以鼓励您扩展代码。这里是一些您可能希望尝试的扩展方案。

 

1.       添加随机数生成器功能

 

          通过在 CalculatorForm.jsl 中的 disableExtendedComponents() 方法中作如下更改，启用窗体上的“Ran#”按钮

 

btnRandom.set_Enabled(true);

 

或者，您只需移除现有行，因为所有按钮都已通过设计器启用。

btnRandom.set_Enabled(true);

 

          创建 RandomNumber.jsl 并实现 Operation，这与 Pi.jsl 实现的方法类似。使用 java.util.Random 生成随机数。

 

          在 CalculatorForm.jsl 的 initializeMap() 方法中，将 btnRandom 映射到相应的对象。

 

mapButtonToAction.put(btnRandom, new RandomNumber());

 

这会将 Random.jsl 中实现的应用程序逻辑与相应的按钮链接在一起。

 

2.       实现阶乘功能

 

          通过在 CalculatorForm.jsl 中的 disableExtendedComponents() 方法中作如下更改，启用窗体上的“n!”按钮

 

btnFactorial.set_Enabled(true);

 

 

          创建 Factorial.jsl 并实现 UnaryOperation。使用递归算法计算某数的阶乘。

 

          在 CalculatorForm.jsl 的 initializeMap() 方法中，将 btnFactorial 映射到相应的对象。

 

mapButtonToAction.put(btnFactorial, new Factorial());

 

这会将 Factorial.jsl 中实现的应用程序逻辑与相应的按钮链接在一起。

 

3.       类似地，实现所有灰显函数（例如 nCr、cos、1/x、sqrt、log 等）的功能。

4.       基于“十进制”和“二进制”基数模式的实现方式，您可以扩展计算器使它拥有八进制和十六进制模式。

5.       扩展计算器，通过实现“Hyp”按钮的应用程序逻辑，使计算器支持三角函数，例如 sinh(x)、cosh(x) 等。
