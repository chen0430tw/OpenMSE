Microsoft Visual Studio Tools for Office

要求: 带有 Service Pack 1 的 Office 2003

Visual Studio 要求您在安装 Visual Studio 之前先 在计算机上安装带 Service Pack 1 的 Office 2003。 您必须首先在这台计算机上安装下列 Office 2003 产品之一:

  • Microsoft Office Excel 2003
  • Microsoft Office Word 2003
  • Microsoft Office Outlook 2003
  • Microsoft Forms 2.0 (在 Office Tools 下)
  • Microsoft Graph (在 Office Tools 下)
  • Microsoft Project (对于 Visual Studio Team Server 产品是必需的)

如果您没有这些应用程序，可以在以下地址找到相关的 详细信息: http://office.microsoft.com/zh-cn/default.aspx。

如果您没有 Office 2003 的 Service Pack 1，可以 从 http://office.microsoft.com/zh-cn/officeupdate/default.aspx 下载并安装该 Service Pack。 在安装该 Service Pack 之后，必须重新启动 Visual Studio 安装程序，请双击安装源 CD、DVD 或网络共享上的 setup.exe， 或单击下载网站上的适当链接。

注意: 强烈建议您定期检查并 安装 Office 2003 的更新。要搜索操作系统的 更新，请参见 http://v5.windowsupdate.microsoft.com/v5consumer/default.aspx?ln=zh-cn。

为什么要安装 Service Pack?

Service Pack 是产品更新发布的途径。Service Pack 所包含的更新可用于提高系统可靠性、程序兼容性、 安全性等等。有关 Microsoft Service Pack 的详细信息，请参见 http://support.microsoft.com/default.aspx?scid=fh;ZH-CN;sp。
