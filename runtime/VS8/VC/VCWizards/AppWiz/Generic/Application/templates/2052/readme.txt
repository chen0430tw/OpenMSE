应用程序向导创建了下列资源：

[!output PROJECT_NAME].rc
这是程序使用的所有 Microsoft Windows 资源的列表。它包括 RES 子目录中存储的图标、位图和光标。此文件可以直接在 Microsoft Visual C++ 中进行编辑。

Resource.h
这是标准头文件，它定义新的资源 ID。
Microsoft Visual C++ 读取并更新此文件。

[!output PROJECT_NAME].ico

此图标包括在主资源文件 [!output PROJECT_NAME].rc 中。

small.ico
这是一个图标文件，其中包含应用程序图标的较小版本 (16x16)。此图标包括在主资源文件 [!output PROJECT_NAME].rc 中。
[!endif]
