1.0 简介

本文件包含有关 Microsoft(R) SQL Server(TM) 2005 Mobile Edition (SQL Server Mobile) 的最新进展、安装说明和其他重要信息。它为 SQL Server Mobile 文档提供了补充。在安装此版本的 SQL Server Mobile 之前，请通读本文件。

【页首】

1.1 获取 SQL Server Mobile

Microsoft SQL Server 2005 和 Microsoft Visual Studio(R) 2005 均附带有 SQL Server Mobile。

您可以在 SQL Server 2005 和 Visual Studio 2005 中找到 SQL Server Mobile 服务器工具文件 (sqlce30setupen.msi)，也可以从此 Microsoft 网站下载 SQL Server Mobile 服务器工具。

SQL Server Mobile 不支持使用 Microsoft eMeddebed Visual Basic 进行开发。

【页首】

1.2 有关 SQL Server Mobile 的其他信息

您可以通过 SQL Server 2005 联机丛书和 Visual Studio 2005 联机丛书访问 SQL Server Mobile 联机丛书文档。在这两种情况下，安装程序均将该文档安装到本地硬盘上。

查看该文档

  • 从 SQL Server 2005 中打开帮助目录，即可查看完整的 SQL Server Mobile 联机丛书。

  • 从 Visual Studio 2005 中打开帮助目录，依次导航到“企业版开发”、“SQL Server”、“SQL Server 2005”，即可查看完整的 SQL Server Mobile 联机丛书。

未及时包括在本自述文件中的任何 SQL Server Mobile 相关信息都将发布到 Microsoft 知识库文章 905395 中。

2.0 安装 SQL Server Mobile

本节包含有关安装的信息。有关安装和配置用于远程数据访问或合并复制的服务器环境的完整信息，请参阅 SQL Server Mobile 联机丛书中的“安装服务器环境”和“配置和保护服务器环境的安全性”。

【页首】

2.1 安装 SQL Server Mobile 服务器工具

如果在使用 Windows 防火墙的运行 Windows XP SP2 的计算机上安装 SQL Server Mobile Edition 服务器工具，则必须专门启用 HTTP 和/或 HTTPS 服务。

启用 HTTP 或 HTTPS 服务

  1. 在控制面板中双击“Windows 防火墙”。

  2. 单击“高级”选项卡。

  3. 在“网络连接设置”中选择连接，然后单击“设置”。

  4. 选择“Web 服务器(HTTP)”或“安全 Web 服务器(HTTPS)”，确保服务器名称或 IP 地址正确，然后单击“确定”。

【页首】

2.2 卸载 SQL Server Mobile 服务器工具

卸载 SQL Server Mobile 服务器工具

  1. 在控制面板中双击“添加/删除程序”。

  2. 从已安装程序的列表中选择“Microsoft SQL Server 2005 Mobile Edition”。

  3. 单击“删除”。

  4. 在卸载后，您应重新启动 IIS 或重新启动运行 IIS 的计算机。

3.0 支持的平台

本版本的 SQL Server Mobile 支持：

  • Pocket PC 2003 平台

  • Windows CE 5.0

  • Windows Mobile Version 5.0 Pocket PC

  • Windows Mobile Version 5.0 Smartphone
