个人网站初学者工具包

介绍

祝贺您!您已经创建了自己的个人网站，该网站包括主页、简历和相册。按 Ctrl+F5 可以立即运行此站点。

只需执行一些小的自定义操作(如添加您自己的内容)，即可按原样使用该站点。此外，您还可以向该站点添加网页。以下各节介绍如何使用个人网站。

创建管理用户

第一步必须先创建一个管理用户。管理用户具有上载照片和创建相册的权限。

创建管理用户

  1. 在继续之前，至少运行一次站点。这可以确保初始化“成员资格”和“角色”数据库。
  2. 在“网站”菜单中，单击“ASP.NET 配置”。
  3. 单击“安全”选项卡。
  4. 单击“创建用户”。
  5. 在“创建用户”框中，键入该管理用户的用户名、密码和电子邮件地址。您还必须提供一个安全问题及答案，用于在必要时帮助您重新获得密码。
  6. 在“角色”框中，同时选中“管理员”和“朋友”这两个复选框，以使该用户成为管理员和朋友角色中的成员。
  7. 单击“创建用户”。
  8. 关闭“网站管理工具”窗口。

管理个人网站

以下各节提供有关如何管理站点的基本信息。

将来宾用户指定为朋友

站点的访问者可以在您的站点上进行注册。您可以将已注册的用户指定为朋友，这样他们就有权查看私人相册了。

授予用户查看私人相册的权限

  1. 在“网站”菜单中，单击“ASP.NET 配置”。
  2. 单击“安全”选项卡。
  3. 在“用户”下单击“管理用户”。
  4. 在用户列表中，单击与该来宾对应的“编辑角色”。(如果您看不到该用户名，请使用搜索框。)
  5. 在“角色”下，选择“朋友”。
  6. 关闭“网站管理工具”窗口。

使用相册

利用相册功能，您可以:

  • 创建用于收藏照片的相册。
  • 将照片分别上载到相册。
  • 将照片集批量上载到相册。此功能有助于基于照片集(如假期照片)创建相册。

创建相册并添加照片

  1. 以管理员身份登录到站点。
  2. 在菜单中单击“管理”。
  3. 在“添加新相册”下键入名称。
  4. 如果您想要所有人都能够看到您的照片，请选择“使此相册成为公共相册”。如果保留此复选框处于未选中状态，则只有注册为朋友的用户才能查看该相册。
  5. 单击“添加”创建相册。 
  6. 在“您的相册”下，单击新相册的空白照片。
  7. 在“添加照片”下，键入或选择照片文件名称，键入标题，然后单击“插入”。
  8. 对于要添加到该相册的每张照片，重复步骤 4。

将照片批量上载到相册

  1. 将照片复制到网站的 Upload 文件夹中。
  2. 在菜单中单击“管理”。
  3. 在相册列表中，单击要使用的相册。(必要时先创建一个新相册。)
  4. 单击“导入”。Upload 文件夹中的所有照片随即添加到该相册中。

发布站点

准备好与他人共享网站后，可以将它复制到 Web 服务器。您需要知道该服务器的文件传输协议(FTP)地址，必要时，还要知道您使用的用户名和密码。

  1. 在“网站”菜单中单击“复制网站”。“复制网站”工具在“源网站”下显示网站中的文件。
  2. 在“连接到”框中单击“连接到...”。
  3. 在“打开网站”对话框中单击“FTP 站点”选项卡。
  4. 键入服务器的 FTP 地址，如果需要，还要键入承载站点提供的用户名和密码。FTP URL 的格式通常为: 
    ftp://ftp.servername/foldername
  5. 单击“打开”。Web 服务器上的文件显示在“远程网站”下。
    注意: 如果连接到服务器时出现问题，请与服务器管理员联系。
  6. 在“移动文件”列表中单击“移动所有源文件到远程网站”。
  7. 单击“复制网站”按钮。您的个人网站中的文件随即复制到该服务器。
