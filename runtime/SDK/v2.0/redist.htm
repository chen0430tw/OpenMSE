Microsoft .NET Framework 可再发行组件包

通过 .NET Framework 可再发行组件包可重新发行 .NET Framework。

有关详细信息，请参阅 MSDN 上的 .NET Framework 部署指南。

Microsoft Visual J# 可再发行组件包

若要运行 Visual J# 应用程序，包括 Visual J# 工具和示例，则必须安装 Visual J# 可再发行组件包 2.0。有关详细信息，请参阅 http://msdn.microsoft.com/vjsharp。

如果在不安装 Visual J# 可再发行组件包 2.0 的情况下运行 JBImp.exe(一个 Visual J# 工具)，则会出现异常错误。

如果不先安装 Visual J# 可再发行组件包 2.0，也无法生成和运行 Visual J# 示例。
