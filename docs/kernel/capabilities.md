# 兼容能力矩阵

实测日期：2026-11-19。本机 Windows、移植运行目录及其现有安装依赖。证据来自本次创建的独立测试实例，不能推断其他版本、干净机器或已有用户会话也通过。

| 能力 | MSE / VS7 核心 | VS2005 / VS8 核心 | 证据与结论 |
|---|---|---|---|
| 旧界面启动 | 已观察 | 已观察 | 两套独立 x86 进程，可同时存在 |
| 按 PID 绑定 DTE | 阻塞 | 已验证 | VS8 ROT 注册 `!VisualStudio.DTE.8.0:<pid>`，再校验主窗口 PID、路径和进程创建时间 |
| NativeOM 自动化备用入口 | 顶层窗口探测失败 | 未测 | MSE 的 `OBJID_NATIVEOM` / IDispatch 返回 0x80004005；不排除其他内部接口 |
| 命令清单 | 桥接不可达 | 观察到 2558 个具名命令 | 清单存在不等于各命令行为通过 |
| 文本文档打开/读取/写入/保存/关闭 | 桥接不可达 | 已验证 | 中文内容经过 DTE 缓冲区并核对磁盘文件 |
| 写入冲突、脏文档关闭、工作区范围保护 | 桥接不可达 | 已验证 | 错误代码与负向测试记录在 transcript 中 |

| 同步构建 | 未测 | 已验证 | 样例构建结束，failedProjects=0；未采集编译器错误数/警告数 |

可复现入口：`scripts/build-bridge.ps1`、`scripts/audit-kernel.py`、`scripts/probe-nativeom.ps1`。测试会创建自己的隐藏 IDE 实例，在 `workspace/kernel-audit` 写入样例，绝不接管任意用户会话。失败的 MSE 连接不会自动关闭 IDE；如仍存活，须按 session marker 校验后关闭本次实例。

原始结果在 `logs/kernel-audit/results.json`；逐条请求和结果在 `*-transcript.json`，VS8 命令清单在 `vs8-commands.json`，MSE NativeOM 探测在 `mse-nativeom.txt`。日志目录不加入 Git，仓库内此矩阵用于保存第一阶段结论。`config/kernel-capabilities.json` 保存精简机器可读结果。
